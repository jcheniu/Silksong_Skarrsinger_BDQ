# 学习路线

## 第 0 阶段：补齐工具

掌握 Python 类、字典、随机数、JSON、命令行参数和 Git。然后阅读 `boss_env.py`，把以下内容写在纸上：状态空间、动作空间、奖励、终止条件、截断条件。

## 第 1 阶段：跑通 Q-learning

运行训练脚本，记录最近 100 局平均奖励、胜率和平均受伤次数。一次只改一个超参数：学习率 `0.15`、折扣因子 `0.95`、最小探索率 `0.05`。

重点问题：为什么不能只奖励“攻击成功”？为什么无伤目标需要对受伤施加强惩罚？

## 第 2 阶段：从表格到函数逼近

先用线性模型或小型 MLP 近似 Q 函数，再学习 DQN：经验回放、目标网络、epsilon-greedy、稳定训练。推荐先在 CartPole 上验证，再回到本项目。

## 第 3 阶段：从状态到图像

把低维状态替换为固定大小的灰度帧，使用连续多帧堆叠速度信息。先做离线数据集和行为克隆，再做 RL，避免一开始就让真实游戏承担所有探索成本。

## 第 4 阶段：真实游戏研究

阅读 `REAL_GAME_PLAN.md`。先实现观测记录和回放评估，再实现只输出建议动作的“影子模式”，最后才考虑在暂停、训练房或自建测试场景中控制角色。
